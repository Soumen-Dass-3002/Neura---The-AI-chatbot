# ⚡ AI Chatbot — Powered by Gemini

A beautiful, animated AI chatbot built with **React**, **Plain CSS**, and **Google Gemini 2.0 Flash**.

![Dark Theme](https://img.shields.io/badge/theme-dark-black) ![React](https://img.shields.io/badge/React-18-blue) ![Gemini](https://img.shields.io/badge/AI-Gemini%202.0-purple)

## 🚀 Quick Start

### 1. Get your Gemini API Key (FREE)
Go to [Google AI Studio](https://aistudio.google.com/apikey) and create a key.

### 2. Configure Backend
```bash
cd backend
# Edit .env and add your API key
GEMINI_API_KEY=your_key_here
```

### 3. Start Backend
```bash
cd backend
npm run dev
```

### 4. Start Frontend (new terminal)
```bash
cd frontend
npm run dev
```

### 5. Open Browser
Go to **http://localhost:3000** and start chatting! 🎉

## ✨ Features
- 🌈 Animated gradient background
- 💬 Smooth message slide-in animations
- ⌨️ AI typing indicator with bouncing dots
- ✨ Glowing input bar
- 🔄 Real-time streaming responses (SSE)
- 📱 Responsive sidebar with chat history
- 🌙 Beautiful dark glassmorphism theme

## 🛠️ Tech Stack
- **Frontend:** React 18, Vite, Plain CSS
- **Backend:** Node.js, Express
- **AI:** Google Gemini 2.0 Flash (free tier)
- **Streaming:** Server-Sent Events (SSE)
